# Founder's Research Notes (TTS Exports)

These are the founder's spoken-word research notes, exported chronologically
from 14 March 2026 onwards. They are preserved unedited in plain text,
formatted for text-to-speech accessibility (no markdown, no code formatting,
no symbols that TTS software would mangle).

They record the thinking as it happened — observations, dead ends, moments
where an idea first appeared before it was formalised, discussions that
shaped design decisions, and exploratory analysis that may not have made
it into the formal documentation. Many of the observations in
[FOUNDERS_NOTES.md](../FOUNDERS_NOTES.md) were first articulated in these
files.

The curated version is FOUNDERS_NOTES.md. These are the raw notes.
