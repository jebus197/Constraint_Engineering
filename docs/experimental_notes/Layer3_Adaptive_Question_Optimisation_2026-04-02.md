## Architecture

### Three Prompt Features

| Feature | Measures | Computation |
|---------|----------|-------------|
| **Referential density** | Distinct domain concepts per 1K tokens | `concept_count / token_count × 1000` |
| **Novelty score** | Fraction of vocab NOT seen in prior rounds | `len(new_tokens) / len(unique_tokens)` |
| **Specificity** | Concentration of concept distribution | Normalised Herfindahl index on concept frequencies |

### Classes

- `PromptFeatures` — dataclass holding the three features plus token/concept counts
- `QuestionOutcome` — `(round_idx, features, per_model_omega, mean_omega)` pair
- `FocusDirective` — steering recommendation with text, reasoning, confidence, predicted lift
- `AdaptiveQuestionOptimiser` — main class with `observe()`, `recommend()`, `get_directive_text()`, `summary()`

### Learning Method

Split-half correlation: sort observations by Ω, compare mean feature value in top half vs bottom half, normalise by range. Directionally robust at small sample sizes (3–10 observations). No scipy dependency.

### Focus Directives (Three Templates)

1. **Referential density → cross-cutting:** "Look for issues spanning multiple subsystems"
2. **Novelty → exploration:** "Focus on areas NOT yet examined"
3. **Specificity → depth:** "Focus deeply on ONE specific area"

## Runner Integration

```
Round start:
  directive = question_optimiser.get_directive_text()
  → passive mode: always ""
  → active mode: prepends focus directive to prompt

Round end (after Ω computation):
  question_optimiser.observe(round_idx, prompt_text, per_model_omega)
  → records features + outcome for learning

Final report:
  question_optimiser.summary()
  → correlations, feature history, recommendation (even if not acted on)
```

## Why Passive for Run 7

Run 7 introduces the Ω churn guard as a new control mechanism. Adding prompt steering simultaneously would confound results. The passive switch makes this a zero-risk addition: feature extraction and observation recording execute, but no prompt is modified and no model behaviour changes.
