## Code changes landed

Fix F1 addressed a latent bug in the SymPy sandbox at `bench/immune_agents.py:977`. The pre-existing state was `global_dict={'__builtins__': {}}`, which caused every SymPy verdict to return UNCERTAIN with the error message "UNVERIFIABLE: name 'Integer' is not defined". The fix expands the allow-list to include SymPy constructors and operators — Integer, Float, Rational, Symbol, Add, Mul, Pow, pi, E, oo, sqrt, Eq, Gt, Lt, Ge, Le, log, exp — while keeping the `__builtins__` dictionary empty so the RCE-blocklist invariant holds. Four regression tests were added to `bench/tests/test_immune_agents.py` under class `TestSympyF1SandboxAllowList`: basic arithmetic resolution, algebraic identity confirmation, RCE blocklist rejection of `__import__('os').system('id')`, and RCE blocklist rejection of built-ins subclass traversal. All four passed in 7.70 seconds.

Fix F2 activated the 1E.10 channel-assignment wrapper at the call site `bench/reference_runner_v2.py:3510`. The prior bare call was `compute_rk(R_old=R_old, q=q, sk=sk_result.sk, nu_b=nu_b, nu_f=nu_f)`. The new call routes through the wrapper: `compute_rk_with_eta_channel(R_old=R_old, sk=sk_result.sk, eta_int=q, m_div=1.0, c_ext=0.0, nu_k=0.0, d=1.0, p=1.0, nu_b=nu_b, nu_f=nu_f)`. At these parameters the wrapper reduces mathematically to the bare form because eta_combined equals 1.0 times q times (1 minus 0 times (1 minus 0)), which equals q, and q_out equals q times 1 times 1, which equals q. The identity was pre-verified across 1,620 parameter combinations within 1 times 10 to the negative 9 tolerance in the 20 April re-audit. A pytest-level regression was added at `bench/tests/test_channel_boundary.py::TestWrapperIdentityModeGridSweep::test_grid_identity_mode` covering 567 parameter triples (nine eta values, nine R_old values, seven sk values) and all passed. The shipping configuration at `bench/exp40_configs/40_gate.json` was updated: `eta_int_modulator_wired_into_compute_rk` flipped from false to true, and the note documenting the 2026-04-21 activation under shadow-promotion-now policy was added in place of the prior deferred-to-Experiment-54 note.

Fix F3 added a debug-mode assertion at the same call site, gated by the `DEBUG_CHANNEL_CHECK` environment variable. When the variable is set, the assertion computes `compute_rk(R_old, q, sk, nu_b, nu_f)` independently and requires the wrapped result to match within 1 times 10 to the negative 9. In production the variable is unset, so the assertion is a no-operation. The purpose is to catch any future refactor that accidentally shifts the identity-mode parameters.

The K/L/M enrichment at `bench/immune_agents.py:5400-5428` extends shadow-audit logging for the physics (K), chemistry (L), and engineering (M) specialist B-cells. The prior log statement recorded only the verdict count. The new log statement records per-verdict detail: claim identifier, verdict, severity, tool used, and a 256-character evidence excerpt, all serialised to JSON. This is the step-one action for the Round 2 Research Question 4 bounding condition: operators now capture the data required to measure whether shadow specialist outputs would distort the `40_gate.json` pass condition if applied live. The `LIVE_SPECIALIST_DOMAINS` frozenset at `bench/immune_agents.py:334` remains at its current four-domain contents (mathematics, statistics, biology, information science). The frozenset flip to add physics, chemistry, and engineering is held until non-distortion is measured across Experiments 40 through 50 rounds. Each domain flips independently at the respective specialist experiment: K at Experiment 51, L at Experiment 52, M at Experiment 53, if non-distortion holds for that domain.
