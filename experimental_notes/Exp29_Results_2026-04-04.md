## Convergence Analysis

**Gamma trajectory:** Linear trend slope = 0.016/round, R² = 0.85, p = 0.001. Final γ = 0.385 sits in Duane "good growth" band (>0.3). The system was still improving faster than its average trajectory at termination.

**Kappa trajectory:** Jump from ~0 to 0.783 at R3 is the session resume boundary (shared context established by conversational relay). From R3 onwards, monotonic trend toward 0.960 — genuine calibration.

**Novel count decay:** Exponential fit N = 33.0 × exp(-0.178t), R² = 0.749. R7 bump (19 novel, z = 2.14) is a statistically significant "second wind" — new directions from R6 amplified by relay, then quickly exhausted in R8 (6 novel). Cumulative novel fraction: 0.60 → 0.48. Convergence is real.

**Immune rejection:** Correlates with repeat fraction at r = 0.870. The immune system responds proportionally to novelty content — spikes when rounds are mostly repeats, drops when mostly novel. Working as designed.

## Cross-Model Engagement Analysis

**Best engagers:** Gemini (structured engagement sections, RFC-grounded falsification), CC2 (systematic multi-model positioning). **Worst:** ChatGPT (zero cross-model references in 9 rounds).

**Key example — Gemini falsifies CC2 (R5):** "CC2 claims `seal_epoch` is flawed because it computes the Merkle tree over ALL records from genesis... I strongly disagree. RFC 9162 strictly specifies cumulative Merkle trees over the entire append-only log... CC2's finding is a false positive."

**Key example — CC2 positions against all models (R6):** "Extends DeepSeek_F013 (which noted merge semantics) and Gemini_F002 R4 (which noted immutability claims) — this is specifically about the quantitative scale mismatch causing directional bias."

**Pattern:** Engagement is intermittent and model-dependent, not a default behaviour. Spikes in R1-2 and R5-6, absent in R0, R4, R8. Broadcast relay enables but does not compel engagement.

## Bugs Found and Fixed During Run

1. **DeepSeek empty response killed experiment (CRITICAL):** R3 DeepSeek returned 0 chars. Safety check triggered experiment-wide stop. Fix: per-model benching via `brain.handle_model_failure()` instead of experiment kill. Only stops if ALL models fail.

2. **Resume directory mismatch:** `LOGS_DIR` used `datetime.now()` on import, creating fresh timestamp on every run. `--resume` couldn't find checkpoint. Fix: `_find_or_create_logs_dir(resume)` globs existing dirs and finds most recent with checkpoint.json.
