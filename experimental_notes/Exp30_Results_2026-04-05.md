## Hot Fixes Applied During Run

1. **Endocrine pacing crash** (`endocrine.py` + `run_exp30_endocrine.py`):
   `context_budget` passed as dict instead of int. Fixed in both runner (pass `max(CONTEXT_CHAR_BUDGET.values())`) and endocrine (defensive guard: `if isinstance(context_budget, dict): context_budget = max(context_budget.values())`).

2. **Directed message accumulation** (`insect_brain.py`):
   Round windowing filter `>= current_round - 1` included two rounds instead of one. Added truncation if exceeds budget.

3. **JSON parser multi-array** (`runner_core.py`):
   Parser only checked first `[{` in response. Codex wraps output in multi-array JSON. Changed `re.search` to `re.finditer`, skipping non-findings arrays.

4. **Double-prefix finding IDs** (`runner_core.py`):
   Models pre-prefixing IDs (CC2 outputs `CC2_F001`) got doubled to `CC2_CC2_F001`. Added prefix check before prepending.

5. **Classifier model ID** (`immune_agents.py`):
   Updated to `anthropic/claude-3.5-haiku` (floating alias). Third fix for this ID.

## Key Findings From Models (Recurring/Confirmed)

1. **Convergence/budget-exhaustion conflation** (CC2, Codex, Gemini, DeepSeek, ChatGPT):
   `check_convergence()` sets `converged=True` at max_rounds. Should be `BUDGET_EXHAUSTED` status.

2. **Z3 if/then always rejects** (CC2, Codex):
   `_verify_z3()` hardcodes `X=True, Not(Y)` — always SAT. Every if/then claim rejected.

3. **Helper T v2 log-odds sign bug** (Gemini, Codex):
   `_confidence_to_log_odds(c)` produces negative values for c<0.5, inverting weak evidence.

4. **Checkpoint recovery amnesia** (ChatGPT, Codex, CC2, DeepSeek):
   model_responses empty after recovery, immune_response not serialised, broadcast context lost.

5. **Persistence completeness gaps** (Codex, ChatGPT, CC2):
   Round JSON omits metrics and immune response. Save happens before metrics computed.

6. **CT partial-evidence overreach** (Codex):
   `_ct_evidence_to_verdict()` uses `>=0.5` threshold instead of documented "all evidence verified".

7. **Directed message round filter off-by-one** (CC2, ChatGPT, DeepSeek, Gemini):
   Filter is one round wider than documented. Most-flagged finding across models.
