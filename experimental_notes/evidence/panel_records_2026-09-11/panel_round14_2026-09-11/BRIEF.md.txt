## SECTION 3 — Attack these specifically

1. **THE RE-STAGING CAN SWEEP IN WORK THE AUTHOR DID NOT STAGE.** `cdsfl_restage_paths` runs `git add -- <path>` on a whole file. If a repair touches a file the author had partially staged with `git add -p`, the unstaged hunks go into the commit. Construct that case. Is the mitigation ("only paths a repair reports") sufficient, or does it need `git stash`-style isolation? If you think it does, show the failure first.
2. **THE PATHSPEC-COMMIT NOTICE IS A STRING COMPARISON.** `cdsfl_warn_if_partial_commit` compares `$GIT_INDEX_FILE` against `git rev-parse --absolute-git-dir`/index, with a `*/index` escape. Its FIRST version used `git rev-parse --git-path index`, which RETURNS `$GIT_INDEX_FILE` when set — a check that compared a variable with itself and could never fire. Find the next such hole: worktrees, submodules, `GIT_DIR` set, a repository whose path contains a symlink (`/tmp` vs `/private/tmp` on this machine).
3. **THE CITATION SPLICE ASSUMES OFFSETS SURVIVE.** `check()` reads each file with `errors="replace"`; `repair()` reads it again without. Show a file where those disagree and the splice lands in the wrong place, or show that the `txt[start:end] != str(line)` guard catches every such case.
4. **`answer_help` NOW REFUSES EVERY ARGUMENT.** I verified by AST walk over every tracked `.py` that nothing invokes the 30 scripts with an argument. Falsify that: shell scripts, Makefiles, notes documenting a command, a test using `shell=True`, the Desktop mirrors, `cdsfl_qc.py`.
5. **THE `usage:` CRITERION IS NECESSARY, NOT SUFFICIENT.** A script could print `usage:` and still do its work. Find one that does, or show the class is empty.
6. **FIX 3 EDITED 30 FILES MECHANICALLY.** Prove no script's no-argument behaviour changed. A diff is not proof; an execution is.
