# logs/_archive/ — Legacy Items

Items retained from before the two-subfolder `confer/` + `chat/` policy
that do not fit either category cleanly. Kept for historical continuity,
not part of the active record.

Contents are not sealed by `scripts/cdsfl_seal_logs.py` (the sealer
skips directories whose names start with an underscore). If an archived
item should be promoted back into the active record, move it into
`confer/` or `chat/` and re-run the sealer.
