The three phases, in words and symbols

Detection. Attack the artefact; update belief that a flaw remains. R_det = R(1−q)/(1−qR), with effective detection q = η·p. Restated findings (η→0) update nothing.

Resolution. Apply the fix; it works with probability σ. R_base = σ·R_det + (1−σ)·R. A failed fix leaves you at the old risk.

Re-injection. The act of changing the artefact adds new risk ν. R_new = R_base(1−ν) + ν. This is the substrate floor: lim R ≥ ν — no amount of detection outruns bad repair. But that bound is slack. Solving the recursion for its fixed point gives the floor actually reached, R* = ν / (q(σ + ν(1−σ))), which is ν/q when σ = 1. Detection quality multiplies the floor, so the trajectory settles above the dashed ν line rather than on it — at the default settings, 2.46× above. The bound is tight only at q = 1. Both lines are drawn.

Scope. A bifurcation diagram, not a data plot — a property of the equations, not an observation of any process. Parameters are indicative; the tool exists so that measured values can replace them.

Break-even. A cycle helps only while ν < ν* = σ·R·q / (1 − qR(1−σ)). Above ν*, stop fixing and defer to the HIL.
