Version: 1.0
Date: 2026-03-14
References: APICS/ASCM CSCP body of knowledge, FM Global Property Loss Prevention Data Sheets, GS1 standards

[HARD constraints — non-negotiable]
1. Lead time is a sum, not a single number. LT = order_processing + manufacturing
   + transit + customs_clearance + receiving_inspection. Every component must be
   estimated independently. Omitting any component understates lead time and causes
   stockouts.
2. Safety stock for normally distributed demand with constant lead time:
   SS = z * sigma_d * sqrt(LT)
   where z = service-level z-score (e.g., z=1.65 for 95%), sigma_d = standard
   deviation of daily demand, LT = lead time in days. For variable lead time:
   SS = z * sqrt(LT * sigma_d^2 + d_bar^2 * sigma_LT^2).
3. Reorder point: ROP = d_bar * LT + SS
   where d_bar = average daily demand. An ROP calculated without safety stock
   delivers ~50% service level (median demand), not the target level.
4. Warehouse cubic utilisation: practical maximum is ~30-35% of total building
   volume. The remainder is consumed by aisles (typically 30-40% of floor area),
   staging areas, dock doors, fire separation, clearance above top-of-stack to
   sprinkler deflectors (typically 18 inches / 457mm per FM Global DS 8-9), and
   structural obstructions. Claims of 60%+ utilisation indicate a calculation error.
5. FIFO (First In, First Out) is mandatory for perishable goods, date-coded items,
   and any product with shelf-life constraints. LIFO causes expiry waste and is a
   regulatory violation for food/pharma. System-enforced FIFO requires directed
   putaway and directed picking — honour-system FIFO does not work at scale.
6. Pick path efficiency: travel time is typically 50-60% of total pick time.
   Random picking is O(n) travel per order. Batch picking amortises travel across
   multiple orders; wave picking synchronises pick release with downstream capacity.
   Ignoring pick path optimisation in throughput calculations overstates capacity.
7. SKU velocity classification (ABC/Pareto): A items (~20% of SKUs, ~80% of
   movement volume) must occupy prime pick locations (golden zone, near shipping).
   Mislocating A items in remote positions directly reduces throughput.
8. Customs clearance time is non-zero and variable: 1-5 business days typical,
   potentially weeks for inspections, holds, or classification disputes. Treating
   customs as instantaneous is a common and costly modelling error.

[SOFT constraints — negotiable]
- Prefer cross-docking for fast-moving items to eliminate storage cost and handling.
- Prefer automated replenishment triggers (min/max, ROP) over manual reordering.
- Target inventory record accuracy >= 99% via cycle counting (ABC-stratified frequency).
- Prefer slotting optimisation reviews quarterly or when SKU velocity profiles shift.

[Verification procedures]
- Check that lead time estimates include ALL components, especially customs and receiving.
- Verify safety stock formula matches the actual demand distribution (normal assumption must hold).
- Confirm warehouse layout accounts for fire code separation distances and sprinkler clearances.
- Check throughput model against PEAK demand (holiday, promotional), not average.
- Verify that pick slot assignments reflect current velocity data, not historical.
- Confirm cycle count programme covers A items more frequently than C items.

[Diagnostic heuristics]
- If service level is below target while inventory sits above plan, check the shape of
  the demand distribution before raising safety stock. Intermittent or lumpy demand
  breaks the normal assumption, and z * sigma_d * sqrt(LT) then buys stock in the
  wrong SKUs.
- If forecast accuracy improves while stockouts rise, check the level at which
  accuracy is measured. Aggregate error falls with pooling while the SKU-location
  forecast that actually drives the reorder point gets worse.
- If bullwhip amplification is being attributed to customer behaviour, check order
  batching and the review period first. Both generate variance amplification with
  perfectly stable end demand.
- If a supplier reports 98 per cent on-time delivery while lines stop, check whether
  the measure runs against the original request date or the latest confirmed date. A
  re-confirmation resets the clock and hides every delay before it.
- If a cycle count finds no discrepancy, check whether the count was blind. A counter
  who can see the system quantity confirms it, so a non-blind count measures agreement
  rather than accuracy.
- If lead time looks stable in the planning system, check the variance of each
  component separately. The mean is usually dominated by transit while the variance is
  dominated by customs and receiving inspection, and safety stock responds to
  variance.
- If a capacity model clears peak volume, check the labour curve and dock-door turn
  time rather than storage cube. Peak is almost always constrained at receiving and
  shipping, not by available volume.
- If an ABC classification has not moved in a year, check whether it was built on
  quantity shipped or on order-line frequency. Slotting responds to pick frequency,
  and a volume-based classification mis-slots high-frequency, low-quantity items.

[Known failure modes]
- Safety stock sized from demand variability with lead-time variability omitted.
- Normal demand assumed for intermittent or lumpy SKUs.
- Reorder point set without safety stock, delivering about 50 per cent service level.
- Lead time carried as a single supplier-quoted number in the item master.
- Supplier on-time performance measured against a re-confirmed date.
- ABC classification built on quantity shipped rather than on pick frequency.
- Peak capacity modelled from average volume, with no labour or dock constraint.
- Phantom inventory: system quantity positive, location empty, pick short.
- Minimum order quantities and supplier batch sizes left out of a reorder model, so
  the calculated order can never actually be placed.

[Exception catalogue]
- The 30 to 35 per cent cubic utilisation ceiling describes conventional racking with
  aisles. An automated storage and retrieval system, mobile racking or a drive-in
  installation removes the aisle and legitimately exceeds it, so a 60 per cent figure
  for an AS/RS is not a calculation error.
- Make-to-order, configure-to-order and engineer-to-order items legitimately carry no
  safety stock and no reorder point. The formulae here assume replenishment against a
  forecast, and applying them to a project item builds stock that can never be
  consumed.
- FIFO is the wrong rule for date-coded stock: the correct discipline is FEFO, and
  strict FIFO will ship an older-received lot with longer remaining life ahead of a
  newer-received lot about to expire. LIFO is also legitimate for non-perishable bulk
  reclaimed from a stockpile, where it is the only physically available order.
- Customs clearance is legitimately near 0 for some regimes. An intra-EU movement
  crosses no customs frontier at all, and an authorised economic operator with
  pre-lodged declarations can clear in minutes. The 1 to 5 business day figure
  describes a third-country import, not every movement.
- Pick path optimisation does not apply to goods-to-person or cross-dock operations.
  Picker travel is effectively 0 in a goods-to-person cell, so the 50 to 60 per cent
  travel share is a property of person-to-goods picking and quoting it elsewhere
  overstates what batching can buy.

[Tool limitations]
- A planning system's lead time field is a parameter someone typed, not a measurement.
  The actual distribution exists only in purchase-order receipt history, which no
  planning run reads.
- A warehouse management system reports the quantity it believes a location holds and
  has no sensor. Phantom inventory is invisible to it by construction; only a count or
  a short pick exposes it.
- Discrete-event simulation of a facility is calibrated on observed cycle times that
  already embed the current slotting and staffing, so it cannot predict the effect of
  changing either without re-calibration.
- A mixed-integer solver returns the optimum for the model supplied. A network design
  omitting duty, minimum order quantities or labour step-costs is optimal for a
  network that does not exist.
- Percentage-error forecast metrics are undefined or unstable at 0 demand, because
  they divide by actual. The intermittent SKUs that cause most stockouts are precisely
  the ones such a metric cannot score.

[Limitations]
- Does not cover reverse logistics or returns processing.
- Does not cover 3PL contract negotiation or rate benchmarking.
- Does not cover customs brokerage (HS code classification, rules of origin, FTAs).
- Does not cover international trade compliance (export controls, sanctions screening).
- Does not cover transportation management (route optimisation, carrier selection).
