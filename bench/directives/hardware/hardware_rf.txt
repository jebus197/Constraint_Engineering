VERSION: 1.0
DATE: 2026-03-14
APPLICABLE STANDARDS: ETSI EN 300 328 (2.4GHz), FCC Part 15, IEC 61000-4-2 (ESD)
COMPONENT REFS: SMA connectors (MIL-STD-348), FR-4 laminate (IPC-4101/21), Rogers RO4003C

[HARD constraints — non-negotiable]

Impedance matching for maximum power transfer: Z_source = Z_load* (conjugate match).
  Mismatch causes reflected power. Reflection coefficient:
  Gamma = (Z_L - Z_0) / (Z_L + Z_0)
  Return loss: RL = -20 * log10(|Gamma|)
  Target RL > 10dB (Gamma < 0.316, <10% reflected power) across operating bandwidth.

Microstrip transmission line impedance (approximate, FR-4):
  Z_0 = (87 / sqrt(Er_eff + 1.41)) * ln(5.98 * h / (0.8 * w + t))
  where h = dielectric height, w = trace width, t = copper thickness, Er_eff ~ function of Er and w/h.
  Er for FR-4 ~ 4.2-4.6 at 1GHz (frequency-dependent; rises at low freq, drops at high).
  50-ohm trace on standard 1.6mm FR-4 (0.2mm prepreg to ground): w ~ 0.3mm.

Ground plane continuity is mandatory under all RF traces and antenna feed lines.
  Any slot or gap in the ground plane forces return current to detour — creates a slot antenna.
  Ground plane cuts increase loop area, radiate, and destroy impedance control.

Quarter-wave matching transformer:
  Z_match = sqrt(Z_1 * Z_2)
  Physical length = lambda / 4 at centre frequency.
  lambda = c / (f * sqrt(Er_eff)) for microstrip (velocity factor ~ 0.55-0.65 on FR-4).
  Bandwidth limited: usable over ~10-15% fractional bandwidth for VSWR < 2:1.

Friis transmission equation (free-space link budget):
  P_r(dBm) = P_t(dBm) + G_t(dBi) + G_r(dBi) - FSPL(dB)
  FSPL = 20*log10(4*pi*d/lambda) = 20*log10(d) + 20*log10(f) - 147.55 (d in m, f in Hz)
  Add fade margin (6-20dB depending on environment), cable/connector losses, and body loss for wearables.

Via transitions in RF paths require ground stitching vias within lambda/20 spacing.
  Without stitching, signal via excites parallel-plate waveguide mode between layers.
  At 2.4GHz in FR-4: lambda ~ 70mm, so stitching vias within 3.5mm of signal via.

ESD protection on all external-facing RF ports per IEC 61000-4-2:
  Contact discharge: +/-4kV (Level 2 minimum), +/-8kV (Level 4 for consumer).
  ESD diode capacitance must be low enough to not detune the RF path (<0.5pF at 2.4GHz).

Antenna keep-out zone: no copper pour (ground or signal) within manufacturer-specified
  clearance area. Typical for chip antennas: 5-10mm clear on radiating edge.

[SOFT constraints — negotiable]

Prefer 4-layer stack-up for RF: signal / ground / power / signal.
  Dedicated ground plane on layer 2 gives controlled impedance for top-layer RF.
Minimise via count in RF signal path (each via adds ~0.1-0.5nH inductance).
Maintain physical separation between RF section and high-speed digital (>10mm or ground moat).
Route RF traces on outer layers where possible (inner microstrip has less predictable Er_eff).
Prefer 50-ohm system impedance (industry standard, widest component availability).

[Verification procedures]

Calculate controlled impedance using PCB stack-up tool (e.g., Saturn PCB, Polar Si9000)
  before layout — verify that manufacturer can hold tolerance (typically +/-10% on Z_0).
Measure antenna return loss (S11) with VNA across full operating band.
  S11 < -10dB required. S11 < -6dB is marginal (25% reflected power).
Calculate complete link budget end-to-end: transmit power + antenna gains - path loss
  - cable losses - fade margin >= receiver sensitivity.
Verify PCB manufacturer minimum trace/space capability vs required RF trace geometry.
Check that component land patterns match manufacturer-recommended footprints
  (RF passives are sensitive to pad geometry — parasitic L and C shift tuning).
Perform pre-compliance radiated emissions scan before formal testing (CISPR 32 / FCC Part 15).

[Diagnostic heuristics]

If S11 is excellent and range is poor, measure total efficiency before re-tuning anything: a
  50-ohm resistor has a perfect return loss and radiates nothing, so a match states only where
  the power went IN, never where it went afterwards.
If measured resonance sits below the design frequency, check ground-plane size and enclosure
  loading before the matching network. A chip antenna's resonance is set largely by the copper
  it sits on, and plastic, a battery or a hand all pull it down.
If S11 changes when the coax is touched or re-dressed, there is common-mode current on the
  cable shield; fit a ferrite or a quarter-wave sleeve and re-measure before believing either
  reading.
If a link falls a factor of 3 short of the Friis budget indoors, check path-loss exponent and
  polarisation alignment before raising transmit power: indoor exponents run 3-4 rather than 2,
  and a cross-polarised pair costs 15-25dB while doubling power buys 3dB.
If a digital block misbehaves only while the radio transmits, trace the return current path and
  look for a trace crossing a plane split before adding shielding. Shielding a return-path
  problem moves the symptom and leaves the cause.
If the prototype needs different matching values from the simulation, check pad parasitics and
  the part's self-resonant frequency before the model: an 0402 capacitor above its SRF is an
  inductor, and SRF falls as capacitance rises.
If 2 nominally identical boards tune differently, check laminate batch and glass-weave
  orientation before the assembly process. FR-4 is a woven composite, and a trace running over
  bundle rather than over resin sees a different local Er.
If receive sensitivity degrades only when a switching regulator is enabled, look for spurs
  spaced at exactly f_sw before suspecting the radio; the spacing names the aggressor with no
  further measurement.

[Known failure modes]

S11 measured with the calibration plane at the cable end rather than at the board connector,
  so fixture loss flatters the return loss.
Antenna characterised on an evaluation board whose ground plane differs in size from the
  product's.
Antenna tuned with no enclosure, battery, display or cables fitted — which are the loading
  that sets the final tuning.
Return loss reported as though it were radiation efficiency.
Er for FR-4 treated as one constant, across frequency and across the panel.
Ground stitching spaced for the fundamental when the frequency that matters is a harmonic or a
  digital edge rate.
Reference plane changed at a layer transition with no adjacent return path, so return current
  detours through the nearest decoupling capacitor.
ESD protection placed inside the matching network, where the diode's capacitance becomes part
  of the tuning and the match cannot be recovered without re-tuning.
Antenna gains mixed between dBi and dBd in one link budget, a 2.15dB error, or conducted
  transmit power compared against an EIRP limit.

[Exception catalogue]

Conjugate match is the criterion for maximum POWER TRANSFER, and it is the wrong criterion at 2
  common planes: a low-noise amplifier input is deliberately mismatched toward Gamma_opt for
  minimum noise figure, and a power amplifier output is matched to a load-pull-determined
  impedance for power or efficiency. A return loss below target at those planes can be the
  correct design.
The RL > 10dB target is a system convention, not physics. A deliberately low-Q,
  mismatch-tolerant antenna in a small product may be specified at 6dB across a wide band
  because total efficiency integrated over that band beats a sharply tuned 10dB match.
Gamma computed against 50 ohms is meaningless where the reference impedance is not 50 ohms.
  Balanced antenna ports, 75-ohm systems and differential feeds must be referred to their own
  Z_0, and a balun's transformation comes before any reflection claim.
Absence of copper is not automatically a defect. Slot antennas, coplanar waveguide sections,
  antenna keep-outs and deliberate voids under inductors are all intentional; the
  ground-continuity rule is about UNINTENDED discontinuities in a return current path.
The microstrip closed form is an approximation over a bounded w/h and copper-thickness range,
  for that geometry alone. Outside it, and for stripline, embedded microstrip or CPW, a field
  solver governs — and solder mask alone shifts Z_0 by a couple of ohms on a thin dielectric.
Friis assumes far field. Inside roughly 2 * D^2 / lambda, and for electrically small antennas
  within about a wavelength, the free-space equation does not apply at all — which is why NFC,
  inductive coupling and very-close-range on-body links are a different regime rather than
  underperforming links.

[Tool limitations]

A VNA measures reflection at its calibration plane. Loss and radiation are indistinguishable in
  S11, so efficiency needs an anechoic or reverberation chamber, a Wheeler cap, or a 3-antenna
  method — never a 1-port measurement.
A 2.5-D or 3-D solver is only as good as the stack-up handed to it. Er, loss tangent, copper
  roughness and mask thickness are inputs, and fabrication tolerance is wider than the solver's
  precision, so a Z_0 quoted to 0.1 ohm against +/-10% manufacturing spread is false precision.
A spectrum analyser set to an arbitrary resolution bandwidth and detector does not return the
  quantity a standard limits. CISPR specifies detectors (quasi-peak, average) and bandwidths
  (9kHz below 30MHz, 120kHz above), and a peak reading overstates against a quasi-peak limit.
A near-field probe locates a radiating structure but has no calibration to a far-field level at
  3m, so it ranks candidates and cannot predict compliance.
A link-budget spreadsheet assumes a static channel. It cannot represent fading statistics, so a
  margin that satisfies mean path loss may still fail a stated percentage of the time — and the
  margin required depends on whether the channel is Rayleigh or Rician, which the spreadsheet
  does not carry.

[Limitations]

Does not cover millimetre-wave design (>30GHz — substrate losses, waveguide transitions dominate).
Does not cover waveguide or cavity filter design (different electromagnetic regime).
Does not cover active phased arrays or beamforming (complex feed networks, calibration).
Does not cover high-power RF (>1W — thermal management, PA linearity, regulatory limits differ).
Does not cover coexistence analysis for multi-radio platforms (Wi-Fi + BLE + cellular).
