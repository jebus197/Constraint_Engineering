1. FIND
Issue: `launch_exp39.py` has no CLI support to pass HIL flags or resume through to `reference_runner.py`, so the claimed HIL workflow in focus area A does not work from the experiment sequencer.
Location:
- `bench/launch_exp39.py:153-170` builds subprocess command with only `run --config ...`
- `bench/launch_exp39.py:344-356` parser lacks `--resume` and `--hil-review`
Evidence:
- `run_sub_experiment()` constructs:
  ```python
  cmd = [
      sys.executable,
      str(RUNNER_PATH),
      "run",
      "--config", str(config_path),
  ]
  ```
  No conditional append of `--hil-review` or `--resume`.
- `main()` only parses `--config`, `--only`, `--skip`, `--dry-run`, `--preflight`.
- Yet `reference_runner.py` added `--hil-review` support (`bench/reference_runner.py:3558-3616` in diff context), and the review focus explicitly asks whether exit 42 propagates through `launch_exp39.py` and whether `--resume` restores cleanly.
FOLLOW
- If operator launches the sequencer with intended HIL review, there is no accepted CLI flag, so HIL mode cannot be enabled through the orchestrator.
- Even if a subexperiment is manually resumed with `reference_runner.py --resume`, the sequencer itself cannot participate in the documented workflow “resume with --resume”.
- The added handling of exit 42 in `RunResult.hil_paused` and `run_sequence()` is therefore only partial plumbing; it reacts to 42 if somehow produced, but cannot initiate or resume that mode.
- This directly affects infrastructure gate 39-0 because pre-launch review focus A requires sequencer propagation correctness.
ANALYSE: CONFIRMED
FIX
- Add `--hil-review` and `--resume` to `bench/launch_exp39.py` CLI.
- Thread those flags into `run_sequence()` / `run_sub_experiment()`.
- Append them to the subprocess command when set.
- Define sequencer exit semantics: if a child pauses with 42, the sequencer should exit 42 rather than printing “All required sub-experiments passed.”
P-PASS
- Could this be non-blocking because 39-0 has `burst_mode: off` and HIL is optional? No. The session change list explicitly adds HIL review gate as a recent change under review, and focus area A asks correctness through the sequencer. The sequencer currently cannot exercise that path as specified. This is a launch blocker for the reviewed change set.
