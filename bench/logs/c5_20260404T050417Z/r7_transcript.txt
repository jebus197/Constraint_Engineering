### FINDING 1: Context-Manager Deadlock (The "Fake Timeout" Illusion)
**Location:** `run_immune_pipeline` (Line 735)
**Category:** Concurrency / Thread Lifecycle

**Structured Certificate:**
*   **Premises:**
    1. The thread pool is managed by a context manager (`with concurrent.futures.ThreadPoolExecutor(...) as pool:`).
    2. The orchestrator enforces timeouts via `future.result(timeout=ct_timeout + 30)`.
    3. `TimeoutError` is caught, logged, and the loop proceeds.
    4. By Python specification, the `ThreadPoolExecutor.__exit__` method implicitly calls `pool.shutdown(wait=True)`.
*   **Execution Trace:**
    *   The `cytotoxic_t_cell` thread hangs (e.g., the `claude` CLI binary stalls due to a network hang or OS pipe deadlock, failing to honour its own timeout).
    *   The orchestrator waits. At `ct_timeout + 30`, `future.result()` raises a `TimeoutError`.
    *   The orchestrator catches the exception, logs "Immune cell failed", and concludes the `for` loop.
    *   The execution reaches the end of the `with` block.
    *   `__exit__` is invoked. It blocks the main thread, waiting for the deadlocked Claude CLI thread to naturally terminate.
*   **Formal Conclusion:** The orchestrator's timeout mechanism is structurally useless. Any thread that exceeds the timeout will permanently hang the entire verification pipeline at the context manager exit boundary, leading to complete system deadlock.

**Falsification Attempt:** Can the process continue? No. `wait=True` is hardcoded into the Python standard library's `__exit__` definition for executors. The main thread will block infinitely. 

**Fix (Architectural): Decoupled Executor Lifecycle**
*   **What it does:** Abandons the context manager for tasks requiring strict timeouts. It spawns daemonized executors that are permitted to be garbage collected, allowing the main pipeline to survive stalled children.
*   **Classification:** ARCHITECTURAL
```python

            # The future is cancelled if it hasn't started, but if it's running, 
            # we must abandon it.
```
