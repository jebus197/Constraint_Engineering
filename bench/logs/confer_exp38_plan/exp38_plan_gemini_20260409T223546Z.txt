### Finding 1: In-Place Test Execution Destroys Sandboxing
**FIND:** `_run_effect_regression` copies the modified file to a temporary directory but executes pytest with `cwd=str(REPO_ROOT)`. 
**FOLLOW:** Pytest resolves imports and module paths relative to its working directory. Because `cwd=REPO_ROOT`, pytest will load the *unmodified* source file from the actual repository, completely ignoring the modified file in the temporary directory. The test will run against the baseline code, producing a false $S_k$ score and blinding the system to regressions.
**ANALYSE:** CONFIRMED. Classification: HARD (Physics/Environment Isolation).
**FIX:** Copy the repository structure to the temp directory so the test runs in a true sandbox containing the modified file.
**FALSIFICATION:**
- *Falsifier:* Copying the entire repository is too slow and will cause timeouts.
- *Attempt:* Exp 38 is running on the `cdsfl` codebase itself, which is lightweight. Excluding `.git` and `__pycache__` reduces copy time to milliseconds. 
- *Result:* Claim holds. A sandboxed copy is necessary and performant.

### Finding 2: Geometric Mean Collapses Graded Evidence to Veto
**FIND:** Artifact 3 `compute_sk` uses geometric mean for the effect evidence ($E$). Artifact 1 states this "preserves graded semantics."
**FOLLOW:** Geometric mean mathematically mandates that if *any* single term is 0, the entire product is 0. If a fix resolves a critical bug but introduces one minor security flag (e4_score = 0.0), $E$ becomes ~0, and $S_k$ evaluates to 0. This gives *every graded effect gate veto power*, functionally destroying the architectural separation between $A$ (admissibility/veto) and $E$ (graded quality). 
**ANALYSE:** CONFIRMED. Classification: HARD (Mathematics).
**FIX:** Revert $E$ to a weighted arithmetic mean. It provides true graded continuity, allowing strong test passage to partially offset minor style regressions.
**FALSIFICATION:**
- *Falsifier:* Arithmetic mean is too forgiving; a fix that fails all security checks could still pass if $E$ remains high enough.
- *Attempt:* The S* threshold (Valley of Bad Fixes) catches this. If security is genuinely non-negotiable, it belongs in the HARD gates ($A$) list, not the effect evidence ($E$) list. Graded lists *must* be mathematically graded.
- *Result:* Claim holds. Arithmetic mean correctly honors the distinction between $A$ and $E$.

### Finding 3: Ruff Non-Regression Punishes Identical States
**FIND:** `_run_effect_ruff` calculates the score as `max(0.0, 1.0 - (new_count / (baseline_violations + 1)))`.
**FOLLOW:** If `baseline_violations` is 10, and the modified code introduces no new violations (`new_count` = 10), the score becomes `1.0 - (10 / 11) = 0.09`. A completely harmless fix is heavily penalized, almost dropping $S_k$ into the Valley of Bad Fixes.
**ANALYSE:** CONFIRMED. Classification: HARD (Mathematics).
**FIX:** Calculate the absolute delta. If there are no *new* violations, the score must be 1.0. Deduct a fixed penalty (e.g., 0.1) for each genuinely new violation.
**FALSIFICATION:**
- *Falsifier:* A fixed penalty of 0.1 is arbitrary and could push the score below zero if there are 11 violations.
- *Attempt:* The `max(0.0, ...)` clamp ensures the score remains bounded in $[0, 1]$. A flat penalty correctly treats style regressions proportionally regardless of the baseline size.
- *Result:* Claim holds. Delta-based penalty is required.

- *Result:* Claim holds. Clamp and connect the loop.
