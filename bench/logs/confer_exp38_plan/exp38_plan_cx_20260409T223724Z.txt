- **ATTEMPT:** Inspected regex; it is pattern-based over raw multiline text, not line-state parsing.

def parse_search_replace_blocks(text: str) -> List[FixBlock]:
    """Parse <<<< SEARCH ... ==== ... >>>> REPLACE blocks line-by-line.

    Delimiters are recognised only when they appear alone as control lines
    (except SEARCH, which includes the file path on the same line).
    Returns an empty list if no complete valid blocks are found.
    """
    blocks: List[FixBlock] = []
    lines = text.splitlines()
    i = 0

    while i < len(lines):
        line = lines[i]
        if not line.startswith("<<<< SEARCH "):
            i += 1
            continue

        file_path = line[len("<<<< SEARCH "):].strip()
        i += 1
        search_lines: List[str] = []
        while i < len(lines) and lines[i] != "====":
            search_lines.append(lines[i])
            i += 1
        if i >= len(lines) or lines[i] != "====":
            break

        i += 1
        replace_lines: List[str] = []
        while i < len(lines) and lines[i] != ">>>> REPLACE":
            replace_lines.append(lines[i])
            i += 1
        if i >= len(lines) or lines[i] != ">>>> REPLACE":
            break

        i += 1
        search = "\n".join(search_lines)
        replace = "\n".join(replace_lines)
        if text.endswith("\n"):
            search += "\n"
            replace += "\n"
        if file_path and search:
            blocks.append(FixBlock(file_path=file_path, search=search, replace=replace))

    return blocks

# Plan-level P-pass

## Surviving assessment of the plan

### What is sound
- The ouroboros framing is valid: a verification system can review its own encodings and runner if the artifacts are treated as ordinary test articles.
- The separation `S_k = A * E` is sound.
- Bounded `nu_eff` is better than the old linear form.
- The Valley of Bad Fixes framing is useful and mathematically coherent.
- SEARCH/REPLACE as the fix format is a strong improvement over NL diff extraction.
- Mandatory template fixes are directionally correct.

### What is incomplete
1. **No explicit baseline-capture execution point in run lifecycle.**
2. **No integration spec for where `compute_sk` is called in the existing runner loop.**
3. **No mapping from finding schema to required threshold inputs (`R_old`, eta, d, p, nu_b, nu_f).**
4. **No statement of how ADMISSIBLE fixes are surfaced to HIL approval pipeline.**
5. **No control/ablation design despite confer mention of three-arm experiment.** That is not strictly required to run Exp 38, but it is required if you want strong causal claims about S_k benefit.
6. **Success criterion 2 is too contingent**: “At least one fix achieves ADMISSIBLE status” is not a robust success criterion, because a clean codebase or bad proposals could fail it without invalidating the framework.

## Revised measurable success criteria
Use:
1. S_k pipeline executes end-to-end on all parseable fixes without runner errors.
2. For at least one candidate fix, gate outputs differ when the modified artifact differs materially from baseline.
3. Thresholding uses finding-level inputs, not hardcoded placeholders.
4. At least one proposal is classified into each reachable status category under controlled fixtures: REJECTED, ADMISSIBLE, and ESCALATE.
5. Telemetry records `A`, `E`, per-gate details, `S*`, threshold decision, and resulting `R_k`.

That would make the experiment falsifiable.
